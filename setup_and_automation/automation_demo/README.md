# Simulation Setup Script

## Overview

This bash script automates the setup process for molecular dynamics simulations, particularly for high-entropy alloys (HEAs). It handles various simulation modes, alloy types, and crystal orientations, creating the necessary directory structure and input files for LAMMPS simulations.

## Features

- Supports multiple simulation modes: relax, heat, and compress
- Default alloy set to NiCoTiZr, but customizable
- Handles crystal orientations 100 and 111
- Automatically creates necessary directory structures
- Generates atomic structures using Atomsk
- Prepares LAMMPS input files based on the simulation mode

## Prerequisites

- Bash shell
- Python (for running HEA_gen.py)
- Atomsk (for creating initial structures)
- LAMMPS (for running the actual simulations)

## Usage

1. Make the script executable:
   ```
   chmod +x auto_simulation.sh
   ```

2. Run the script:
   ```
   ./auto_simulation.sh
   ```

3. Follow the prompts to enter simulation parameters:
   - Simulation mode (relax, heat, compress)
   - Alloy type (default: NiCoTiZr)
   - Crystal orientation (100 or 111, default: 100)
   - Session name
   - Duplication factors (X, Y, Z)
   - PE number
   - Number of cores to use
   - Number of runs

4. For compress mode, you'll also be prompted for temperature.

5. The script will create the necessary directories, generate the atomic structure, and prepare the LAMMPS input files.

6. At the end, if you are already connected to the compute machine (e.g., amd01), the script will automatically run the LAMMPS simulation. Otherwise, you'll need to manually execute these commands or set up a separate process to run them.

## Directory Structure

The script creates the following directory structure:

```
[SIMULATION_MODE]/
└── [ALLOY]_[ORIENTATION]/
    ├── structure/
    │   ├── [ALLOY]_[TOTAL_ATOM].pos
    │   └── [ALLOY]_[TOTAL_ATOM].lmp
    └── [SESSION_NAME]/
        └── in.[SIMULATION_MODE].[ALLOY]
```

## Files Generated

- `[ALLOY]_[TOTAL_ATOM].pos`: POSCAR file generated by Atomsk
- `[ALLOY]_[TOTAL_ATOM].lmp`: LAMMPS structure file generated by HEA_gen.py
- `in.[SIMULATION_MODE].[ALLOY]`: LAMMPS input file for the specified simulation mode

## Notes
- The script assumes the existence of `HEA_gen.py` in the user's directory for generating LAMMPS structure files.
- Template files (`in.relax.var.[ALLOY]` and `in.compress.var.[ALLOY]`) should be present in the user's directory.
- pe directory that contains MEA_var[VAR_NUM].snapcoeff and MEA_var[VAR_NUM].snapparam should be present in the user's directory.
- If you are already SSH'ed into the compute machine (e.g., amd01) when running this script, it will automatically execute the LAMMPS simulation at the end.
- If you are not on the compute machine, the script will provide the necessary commands to run the simulation, but you'll need to manually execute these commands after connecting to the compute machine.
- The script uses nohup to run the LAMMPS simulation in the background, allowing it to continue even if the SSH session is closed.
- Always check the STDOUT file for the simulation progress and any potential errors.

## Customization

You can modify the default values in the script to suit your specific needs:
- `DEFAULT_ALLOY`: Change the default alloy type
- `DEFAULT_ORIENTATION`: Change the default crystal orientation

## Troubleshooting

If you encounter any issues:
1. Ensure all prerequisites are installed and properly configured.
2. Check that all necessary template files are present in the correct locations.
3. Verify that you have write permissions in the directory where you're running the script.

For any persistent issues, please contact the script maintainer.
